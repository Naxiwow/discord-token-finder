## ◈ &nbsp; Features

```
◉  Scans all Discord clients and modded forks automatically
◉  Validates each token against the Discord API in real time
◉  Shows the username tied to each valid token
◉  One-click copy — no CMD flash, no console window
◉  Clean dark UI — no terminal needed to run
◉  100% local — zero network calls except Discord API validation
```
