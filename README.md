## What it does

Scans your local machine for Discord tokens stored by Discord, Chrome, Edge, Brave, Opera and Opera GX.  
Validates each token against the Discord API to show which ones are active.

- No data sent anywhere — 100% local
- Works on Windows only
- GUI app built with Python + pywebview
